# LucKey's 키박스 · 이미지 저장소

블로그(blog.naver.com/theluckeys)에 쓰는 게임 캡처 이미지 모음입니다.

## vs/ · 뱀파이어 서바이벌
| 폴더 | 내용 |
|---|---|
| run | RUN 공략 글용 플레이 장면 |
| st | 스테이지 카드, 스테이지 목록 |
| cr | 캐릭터 그림 |
| pu | 파워업(강화) 화면 |
| ul | 업적 목록 화면, 첫 판 업적 팝업 |
| ul_all | 업적 하나씩 (조건 + 보상) |
| col | 컬렉션 화면 |
| col_all | 컬렉션 아이템 하나씩 |
| se | 비밀 하나씩 |
| be | 우화집 몬스터 하나씩 |
